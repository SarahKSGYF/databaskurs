Databasen innehåller flera kunder och böcker.
Kunder kan sedan skapa beställningar som hämtar info från böcker och skapar order rader.

En kund kan skapa flera beställningar men en beställning kan bara ha en kund.
Beställningar kan ha flera orderrader men en beställning kan bara ha en kund.
En orderrad kan ha flera böcker av en typ i sig.





Med Workbench så finns det en Data export/import som hanterar mysqldump för backups.



Med så många användare så behövs det nog ett event som tar bort inaktiva användare från indexen.

Just denna databas värkar vara byggd för att vara knuten till något annat program som hanterar allt annat än infromation sparningen.
